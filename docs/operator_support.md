# DexSim 0.2.0 operator support

The single-core D2D Python SDK formally supports all 11 legal RTL primitive subops on command context/core0: ABS, Add-Reduce, Compare-Reduce, GEMM, SCALE, ADD, Sin, Cos, Softplus, Assemble and Transpose. GEMV, DOT and OUTER are supported as exact GEMM command forms.

The authoritative installation, API and validation guide is [python_sdk.md](python_sdk.md).
